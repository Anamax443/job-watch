Cloudový agent (Cloudflare Worker), který každý den prohledá zdroje volných míst, vybere pozice vedoucí IT / IT manažer / Solution Architect, ohodnotí je AI, u agenturních inzerátů dohledá skutečného zaměstnavatele a pošle nové nálezy na Telegram / e-mail / Slack.

Obsah: Co to dělá · Zdroje · Pipeline · Notifikace · Stránky · Nastavení · Provoz · Klíče · FAQ

Co to dělá

Každé ráno v 07:00 (cron) běží v cloudu pipeline: stáhne nové inzeráty z více zdrojů, levně je předfiltruje, AI je ohodnotí, sloučí duplicity, u agentur dohledá původce a relevantní nové pozice ti pošle. Vizuální průvodce je na stránce Jak to funguje.

Zdroje — kde hledá

ZdrojPopis
MPSV / ÚP ČRoficiální otevřená data — všechna ohlášená volná místa v ČR, denní přírůstky, bez bot-ochrany. Jádro.
ATS firemveřejná JSON API náborových systémů (Recruitee, Greenhouse, Lever, Ashby, SmartRecruiters). Cíle se dynamicky objevují a ukládají do DB — žádný statický seznam.
Celý webotevřené hledání podle role napříč internetem (AI + web search). Inzeráty můžou být kdekoliv, takže se nespoléhá na pevný seznam portálů.
Personálkyklasifikace agentur (registr agentur práce + heuristika) → spustí deanonymizaci původce.

Co přesně se v daném běhu prohledalo a kolik se stáhlo, uvidíš v stavovém okně na dashboardu.

Pipeline

fetch (MPSV + ATS + web)
  → prefilter (CZ-ISCO 133 + klíčová slova)
  → dedup (sloučení duplicit napříč zdroji)
  → score (AI 0–100 + zdůvodnění)
  → enrich (u agentur: dohledání původce přes web)
  → notify (Telegram / e-mail / Slack)
  → discover (naučení nových zdrojů pro příště)

Nastavení

Veškerá konfigurace (klíčová slova, CZ-ISCO prefixy, práh notifikace, cílový e-mail, Telegram chat_id, zapnuté kanály) se edituje v UI na /settings a ukládá se do databáze. Cron ji čte při každém běhu — co naklikáš, hned platí. Citlivé klíče (API klíč, tokeny, Slack webhook) se nastavují jako secrets, ne v UI.

Provoz — nezávislé na PC

Celý běh jede v Cloudflare (Worker + cron + databáze D1) — lokální počítač se k provozu nepoužívá. Stav, naučené zdroje i nastavení žijí v cloudu. Deploy lze řídit i z GitHub Actions.

Klíče (secrets)

wrangler secret put ANTHROPIC_API_KEY     # nutné pro AI (scoring, web, deanonymizace)
wrangler secret put TELEGRAM_BOT_TOKEN    # Telegram
wrangler secret put GRAPH_TENANT_ID       # e-mail (MS Graph)
wrangler secret put GRAPH_CLIENT_ID
wrangler secret put GRAPH_CLIENT_SECRET
wrangler secret put GRAPH_MAILBOX
wrangler secret put SLACK_WEBHOOK_URL     # volitelné — Slack
⚠️ Bez ANTHROPIC_API_KEY AI část (web-hledání, scoring, deanonymizace) nic nevrátí a skóre bude 0. MPSV jede i bez klíče.

FAQ

Proč je dashboard prázdný?

Buď ještě neproběhl běh (klikni „▶ Spustit teď"), nebo není nastavený API klíč.

Jak poznám, že to něco dělá?

Stavové okno na dashboardu ukazuje živý log běhu; v patičce tikají hodinky a je tam číslo nasazené verze.

Ochrana přístupu

UI je zatím veřejné. Přihlášení jen pro tebe lze zapnout přes Cloudflare Access (Zero Trust) — je to konfigurace, beze změny kódu.
